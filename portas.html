Pergunta 1 de 7

Computador ligado: o que você consertou

Portas lógicas

  • AND: só passa energia se as duas entradas forem 1 (1 e 1 → 1).
  • OR: passa se pelo menos uma entrada for 1 (1 ou 0 → 1).
  • NOT: inverte a entrada (0 vira 1 e 1 vira 0).
  • XOR: passa só quando as entradas são diferentes (1 e 0 → 1).

Resultado das contas de clock

  • Conta 1: período de 0,5 ns → f = 1 / 0,5 ns = 2 GHz (menor valor que atende).
  • Conta 2: 4 ciclos × 750 milhões de instruções/s = 3 bilhões de ciclos/s = 3 GHz.

Ordem do armazenamento

Da mais lenta para a mais rápida: RAM → CACHE → REGISTRADORES.

A RAM é a memória principal, a cache guarda cópias dos dados mais usados e os registradores ficam dentro da CPU.
